# 27.2 release guest control — 2026-11-04

VMPal guest `macOS VM 1`: `sw_vers` printed macOS **27.2**, **26B123**.
DuoUpdater guest process PID 53666, `/Applications/DuoUpdater.app/Contents/MacOS/DuoUpdater`.
Its panel identifies version **0.5.21**. The host bundle also reports **0.5.21**
(build 139 on host; guest build number and executable checksum were not checked).

Guest UI is a virtual framebuffer: the host AX tree exposes VMPal's toolbar,
not the guest apps. The following commands were therefore executed in **guest
Terminal**, using System Events in the guest. The user explicitly authorized
Terminal's Automation and Accessibility permissions in this VM and manually
enabled the latter. Terminal had to be restarted before it took effect.
Earlier permission errors and one malformed AppleScript command are excluded.

Menu item identification succeeded:

```applescript
tell application "System Events" to tell process "DuoUpdater" to get {name, description} of menu bar items of menu bar 2
-- Number Three In A Filled Circle, status menu
```

Single press: before and after window counts **0, 0**; no panel appeared.
Then three repeated presses:

```applescript
tell application "System Events"
    tell process "DuoUpdater"
        repeat 3 times
            perform action "AXPress" of menu bar item 1 of menu bar 2
            delay 1
            log (count windows)
        end repeat
    end tell
end tell
-- 0
-- 0
-- 0
```

The script completed without an action error, but no panel appeared. A subsequent
ordinary mouse click on the same visible circled-3 menu bar icon **did open**
the DuoUpdater 0.5.21 panel, which was observed and left open.

Host 27.3 beta `26C5035r`: `axpress-duoupdater.txt` records a single AXPress
opening a 370×449 on-screen window in 0.13 s. Same marketing app version,
different installation/hardware environment and different AX client; therefore
this is a practical control, not a byte-identical binary/identical-hardware A/B.
The old minimal SwiftUI test app on the host independently opened through AXPress
5/5 usable trials, versus 0/3 on the previously documented 27.2 RC1.

No VoiceOver session or framework binary diff was performed. Earliest fixed build
between 27.2 release and the tested 27.3 beta has not been narrowed further.
